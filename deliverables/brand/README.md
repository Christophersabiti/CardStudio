# Card Studio brand kit

- `card-studio-logo-dark.png`: transparent 2400 × 480 logo, dark lettering for light backgrounds.
- `card-studio-logo-light.png`: transparent 2400 × 480 logo, light lettering for dark backgrounds.
- Matching SVG files: editable text with an embedded raster symbol (not fully vector artwork). Arial/Helvetica font fallback; use PNG for consistent sharing.
- `card-studio-icon.png`: original generated symbol.
- `icon-16.png`, `icon-32.png`: browser sizes.
- `icon-180.png`: Apple touch icon.
- `icon-192.png`, `icon-512.png`: app/profile icons.
- `favicon.ico`: browser favicon.

Palette: charcoal #202421, warm white #FCFCF8, lime #D9EF88. Leave clear space around the logo of at least one dot diameter. Preserve proportions. Use the symbol alone at small sizes. Avoid placing dark lettering on dark backgrounds.

Website assets live in public/brand. Regenerate exports with `node scripts/build-brand-assets.mjs`.

See name-check.md before committing to the name commercially.
